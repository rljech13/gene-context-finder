# Minimal synthetic study

Two unrelated artificial protein families, two artificial assemblies and exact matching GFF3/protein/CDS records. These files are software controls, never biological findings or predictor training data. No pluripotency gene or real species is required.

Copy `project.json` and these compact inputs into a working folder, then validate and run STOP1. BLAST+ and samtools are required for the search. Both families must produce two loci, one per assembly. Review is manual. Model preparation needs an appropriate predictor and naming database; this synthetic example does not benchmark Tiberius or waive its preparation step.
